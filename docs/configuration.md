# Configuration

Every environment variable, read from `.env` (copy `.env.example`; `./install.sh -e` writes one with generated secrets) and, for the relay, `relay.env` ([relay.md](relay.md)). A value that names no secret is also passed to each signed-in device. The server checks all of this at startup and lists every problem ([setup.md](setup.md#when-it-will-not-start)).

| Variable | Purpose |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API key, on the relay (required when its `SPINE_LLM_PROVIDER=anthropic`); the server holds no model credential |
| `SPINE_LLM_PROVIDER` | The relay's provider: `anthropic` (default) \| `vertex`. The server logs it and tells devices `relay` |
| `SPINE_LLM_MODEL` | Model id (default `claude-haiku-4-5-20251001`) |
| `SPINE_LLM_ENDPOINT` | Explicit endpoint. **Required for `vertex`, never defaulted** — residency is a property of the endpoint |
| `SPINE_LLM_REGION` | Provider region (required for `vertex`, e.g. `eu`) |
| `SPINE_LLM_PROJECT` | GCP project (required for `vertex`) |
| `SPINE_LLM_MODELS` | Other models offered in a picker for "Read page with AI" and "Read whole document": `id` or `id=Label`, comma separated, on the same provider, endpoint, region and project unless an entry names its own region (`id|europe-west4=Label`). The default model is always first; an id not listed is refused (400) |
| `SPINE_LLM_MAX_TOKENS_CONTINUATION` / `_EXTRACTION` | Output caps (1024 / 16384). `SPINE_LLM_MAX_TOKENS_PAGE` (16384) caps a page reading. All are ceilings: only generated tokens are billed |
| `SPINE_LLM_CONTEXT_CHARS` | Context window in characters, the only cap on request text (default 300000); longer documents are chunked |
| `SPINE_TRANSLATION` | `off` to stop translating documents (the interface stays translated; content shows in its original language). Default on: translating sends the document's extracted text and the owner's notes to `SPINE_LLM_PROVIDER` (SECURITY.md **M-13**) |
| `SPINE_EMBEDDINGS` | `none` (default) \| `vertex`: embed each document's summary card for related documents and search by meaning. Endpoint, region and project come from `SPINE_EMBEDDING_ENDPOINT/_REGION/_PROJECT` or the Vertex chat settings; **never defaulted**. `SPINE_EMBEDDING_MODEL` (default `gemini-embedding-2`, called with `embedContent`; what the `eu` multi-region serves) and `SPINE_EMBEDDING_DIMS` (768) define the vector space (SECURITY.md **M-15**) |
| `SPINE_CHAT` | `off` removes the chat panel and the recipient's chat on share links. Default on: each question sends the question and the matching documents' summary cards, notes and results (never a page image; the text of a few pages only when the owner asks the assistant to sort an upload, `read_pages`) to `SPINE_LLM_PROVIDER` (SECURITY.md **M-18**) |
| `SPINE_LINKING` | `off` to stop looking for links between documents (a consultation and the tests it asked for, a follow-up). Default on: it sends the summary cards of up to seven documents per call to `SPINE_LLM_PROVIDER` (SECURITY.md **M-16**). Links added by hand still work |
| `SPINE_LLM_CONCURRENCY` | Model calls in flight at once (1-16, default 4); DB writes stay sequential |
| `SPINE_LLM_DAILY_CALLS` | Model calls allowed a day to each device (the server passes it on; default 5000, `0` for no ceiling); past it a call is refused before it reaches the provider. The bound across devices is the relay's per-account count (SECURITY.md **S-35**, **M-35**) |
| `SPINE_LLM_MAX_RETRIES` | Retries inside the adapter (default 2) |
| `SESSION_SECRET` | ≥32 char random string for cookie signing |
| `SPINE_DOMAIN` | Domain nginx serves from (e.g. `spine.yourdomain.com`) |
| `SPINE_LANDING_URL` | Where the "Shared securely via Spine" footer on a shared page links to (`landingUrl()` in `config.ts`). Unset (or anything but an https address or `off`): this instance's own front page, `/`; an https address: that address; `off`: the footer is text. Reaches the recipient's browser through `GET /api/shared/:id/config`, because that core cannot read the server's environment |
| `SPINE_DEMO_UPLOADS`, `SPINE_DEMO_MAX_UPLOADS`, `SPINE_DEMO_MAX_PAGES` | `on` lets a visitor with no account read files of their own in the demo (default off), up to 3 files, the first 5 pages of each (`demoUploads()` in `server/src/config.ts`; a bad number gives the default). Served to the demo's core by `GET /api/demo-relay/config`, with a pass from `POST /api/demo-relay/token` for `demo:<keyed hash of the address>`; the relay's `SPINE_RELAY_DEMO_DAILY_CALLS` (40) and `SPINE_RELAY_DEMO_TOTAL_DAILY_CALLS` (400) are the bound (SECURITY.md **M-39**) |
| `SPINE_OPERATOR_NAME`, `SPINE_OPERATOR_CONTACT`, `SPINE_LEGAL_DIR` | Who the privacy notice and terms name as the controller and where to write to them (default "the operator of this instance"), and a directory of your own `privacy.md`, `terms.md`, `purpose.md` instead of the shipped drafts in `docs/legal/` |
| `SPINE_REPO_URL` | Optional. Repository URL that nginx redirects `/source`, `/docs` and `/security` to (read by `install.sh -n`, not by the server); unset leaves the redirects out |
| `DATA_DIR` | Where the server's database, the vault and the shares live (the server's default is `<repo>/data`, wherever the process starts; core has no default and fails if a host registers none) |
| `SPINE_STORE`, `SPINE_DATABASE_URL`, `SPINE_DATABASE_POOL` | `sqlite` (default; a file at `SPINE_DB_PATH` or `DATA_DIR`) \| `postgres`: the address (`postgres://…`, with `sslmode=require` off this host) and connections per instance (10). The server's store only: records are on the device, so a device or a test of one refuses `postgres`. A Postgres database is backed up by its host, not by `backup.ts` |
| `SPINE_BILLING`, `PADDLE_ENVIRONMENT`, `PADDLE_API_KEY`, `PADDLE_WEBHOOK_SECRET`, `SPINE_PADDLE_PRICE_YEAR`, `SPINE_PADDLE_PRICE_MONTH`, `SPINE_PADDLE_PRICE_FOUNDING`, `SPINE_PADDLE_PRICE_FAMILY_YEAR`/`_MONTH` (the family plan, both or neither), `SPINE_CHECKOUT_URL`, `SPINE_WAITLIST` | Plans and payment (`docs/billing.md`, SECURITY.md **M-45**): `on` gives accounts a six-month trial, a free plan and Premium, with Paddle as seller of record; every Paddle setting is then required, and `SPINE_INSTANCE=private` refuses it. Off (default) means no plans and only the instance's own ceilings. `SPINE_WAITLIST=on` shows "Tell me when Spine opens" on the front page |
| `SPINE_OBJECTS`, `SPINE_GCS_BUCKET`, `SPINE_GCS_PREFIX` | Where the sealed bytes (the vault's objects, a share's copies) are kept: `filesystem` (default; files under `DATA_DIR`) \| `gcs` (a Google Cloud Storage bucket, reached as the process's own identity, no key file; `SPINE_GCS_PREFIX` puts one instance's objects under a prefix). A bucket's versioning or soft delete is then their backup (SECURITY.md **M-46**), and `backup.ts` mirrors no files |
| `PORT` | Fastify listen port (default `3000`) |
| `SPINE_PARSER` | `text` (default: the PDF's own text layer; nothing leaves the host; `sidecar` is the old name) \| `ocr` (text layer, then local Tesseract; nothing leaves) \| `multimodal` (a vision model reads every page) \| `hybrid` (text layer first, then local OCR unless `SPINE_OCR=off`, then a vision model for the pages still unread) |
| `SPINE_MULTIMODAL_ENABLED` | `true` to allow page images to be sent to the LLM provider. **A second switch on purpose**: `multimodal`/`hybrid` without it refuse to start |
| `SPINE_OCR` | `off` skips local OCR in `hybrid`: a page with no text layer goes straight to the model, and Tesseract is not needed (default on) |
| `SPINE_TEXT_LAYER_MIN_CHARS`, `SPINE_OCR_MIN_CONFIDENCE`, `SPINE_OCR_MAX_LOW_SHARE`, `SPINE_OCR_LANGS` | `hybrid`'s screening thresholds (50 / 85 / 0.10) and Tesseract languages (`ron+eng`; the packs ship with the web app). First guesses: tune from the `page routed` lines in the browser console |
| `SPINE_REGISTRATION` | `operator` (default: accounts come from the CLI) \| `open` (signup with email verification; **refuses to start without a mailer**) \| `approval` (people ask for an account and it waits for the administrator; needs no mailer, SECURITY.md **M-44**) |
| `SPINE_INSTANCE`, `SPINE_ADMIN_EMAILS` | `private` labels the deployment as private (front page, sign-in, `/trust`) and refuses `SPINE_REGISTRATION=open`; default `public`. `SPINE_ADMIN_EMAILS` (comma separated) are the signed-in addresses that see and decide the accounts waiting under `approval` on the account page; the CLI needs none (SECURITY.md **M-44**) |
| `SPINE_MAILER` | `none` (default) \| `brevo` |
| `BREVO_API_KEY`, `SPINE_MAIL_SENDER` | Required for `brevo`. The sender has no default: pick a neutral name, it is visible in the recipient's inbox |
| `SPINE_TRUSTED_PROXIES` | Comma separated addresses of a proxy that is not on this host and whose `X-Forwarded-For` is believed (the Compose proxy); loopback is always trusted; a wide range or `true` stops startup (`trustedProxies()`, **S-31**) |
| `SPINE_RELAY_DOMAIN`, `COMPOSE_PROFILES=relay` | The relay on this machine: its own hostname (`SPINE_RELAY_URL` is then `https://<it>`), read by `install.sh -r`/`-n` and Caddy, and the profile that starts Compose's `relay` service. Its provider key is in `relay.env`; it listens on `SPINE_RELAY_HOST`/`SPINE_RELAY_PORT` (`docs/relay.md`) |
| `SPINE_RELAY_URL`, `SPINE_RELAY_SECRET` | The relay a device sends model calls to (https, or `http://localhost` to try one) and the secret (32+ characters) shared with it, which signs the ten-minute passes `GET /api/relay/token` gives. Unset: a device cannot call a model. The relay's own settings, including the store its daily count lives in, are in `docs/relay.md` (SECURITY.md **M-35**) |
| `SPINE_TRUST_ANCHORS_DIR` | A directory of certificates (`.pem`, `.crt`, `.cer`, `.der`) the operator trusts as authorities for digital signatures; served at `GET /api/trust-anchors`. With them a signer whose certificates chain to one is filed `verified_signature` (SECURITY.md **S-23**); without, a signature is a label. Nothing ships by default: pick them yourself (for Romania, the qualified trust service providers on the EU trusted list) |
| `SPINE_VAULT_MAX_MB`, `SPINE_VAULT_MAX_OBJECT_MB` | What one account may keep in its vault, sealed objects only (default 5120 and 100); a bad value gives the default |
| `SPINE_SHARE_MAX_MB`, `SPINE_SHARE_MAX_TOTAL_MB`, `SPINE_SHARE_MAX_LIVE` | What one account may keep as sealed shares: one object (default 100 MB), all live shares together (1024 MB) and how many are live at once (50); a bad value gives the default (`sharedLimits()` in `server/src/config.ts`) |
| `SPINE_GEOIP_DB`, `SPINE_GEOIP_URL` | The country a share was opened from is read from `data/geoip/country.mmdb`, which `server/src/geoip-update.ts` downloads (from `SPINE_GEOIP_URL`: https, or http to this machine, default the ip-location-db release on GitHub). `SPINE_GEOIP_DB` names a `.mmdb` country file of your own instead, and nothing is downloaded (`server/src/geo.ts`) |
| `SPINE_HOST` | Interface Fastify binds (default `127.0.0.1` — nginx is the only public listener) |
| `SPINE_BACKUP_DIR` | Snapshot + vault mirror target (default beside `data/`; set it to removable or network storage to survive media loss) |
| `SPINE_BACKUP_KEEP` | Snapshots to retain (default `7`) |
| `SPINE_SESSION_IDLE_HOURS`, `SPINE_SESSION_DAYS` | A sign-in ends after this long unused (24) or this long in all (14 days); a bad value gives the default (SECURITY.md **M-27**) |
| `SPINE_SKIP_AUDIT` | `1` lets `install.sh -b` build despite a high or critical dependency advisory (offline builds); default is to stop (**S-32**) |

`SESSION_SECRET` (≥32 chars) is validated at startup and by `install.sh -s`: a missing, short or placeholder value stops the process rather than falling back to a default (SECURITY.md **P3**). There is no shared password: users sign in with an email and their own password.
